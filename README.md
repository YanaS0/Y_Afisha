Анализ поведения пользователей Яндекс Афиши.
Проект направлен на выявление факторов, повышающих вероятность повторных покупок на платформе. Цель — улучшить удержание клиентов и оптимизировать маркетинговые стратегии.

Что анализируем:

- паттерны поведения пользователей;
- факторы, влияющие на возврат клиентов;
- характеристики «постоянных» пользователей.
  
Данные:

Реальные данные сервиса Яндекс Афиша, включая: 
- историю заказов пользователей;
-  демографические и географические данные;
-   информацию о мероприятиях.

Используемые инструменты:

- Python;
- Pandas, NumPy — обработка данных;
- Matplotlib, Seaborn — визуализация;

Как запустить анализ:

1. Клонируйте репозиторий.
2. Установите зависимости из requirements.txt: pip install -r requirements.txt.
3. Запустите Jupyter Notebook (jupyter notebook).
4. Откройте ноутбук analysis.ipynb и выполните ячейки последовательно.

Результаты:

В репозитории доступны: 
- отчёты с промежуточными результатами;
- ключевые графики и визуализации;
- выводы и рекомендации для маркетинга.
